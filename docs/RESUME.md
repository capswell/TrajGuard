# 贡献与简历表达

推荐名称：TrajGuard——机器人多模态轨迹数据质检与处理工具。定位为基于开源 Demo 的工程改造，保留上游来源，区分上游能力和个人实现。

## 可展示贡献

1. 重建 ALOHA/robomimic 风格多 episode 解析和统一输出，区分状态语义、时间来源、动作策略。
2. 保留 JPEG 编码字节并分批复制，避免整段图像提前解码；记录来源 SHA256、源帧索引和配置。
3. 共同时间范围内有界重采样，离散动作前值保持；帧数相同也检查时间偏移，时间缺失明确退化。
4. 累计运动量避免往返误判，速度使用 Δq/Δt；显式检查列排除不同量纲夹爪。
5. 输入/配置签名驱动断点恢复、成品校验、原子写入、多进程与单轨迹故障隔离。
6. HTML 报告、人工审核队列、离线标签来源/审核状态校验，保留原始指令。

## 草稿

> 基于开源 Demo 设计并实现 TrajGuard 轨迹质检工具，支持 ALOHA/robomimic 风格 HDF5 多轨迹解析、压缩图像保留、时间重采样及规则审核；通过输入/配置签名、原子写入和成品哈希实现可追溯批处理与断点恢复。
>
> 针对首尾位移误判、同帧数时间错位及离散动作插值问题建立回归测试，提供可筛选 HTML 报告和轨迹审核队列。

测试数量以 pytest 实际输出为准。7 个受控样例匹配不能写成“真实数据准确率 100%”。纯色 JPEG 小样本不能写成工业级 50GB 提速。单 worker 峰值不是池总内存。没有真实模型/人工审核实验，不能写高质量自动标注；没有策略训练对比，不能写提高机器人成功率。

## 下一步实验

- 在语义明确的真实数据上人工复核，统计正常轨迹误删率、异常精确率与召回率。
- 固定硬件/数据/压缩设置，比较内存、I/O、进程数与多次运行分布。
- 添加训练导出器，在相同预算下比较原始与筛选数据，避免数据泄漏。
- 有模型条件后比较关键帧采样策略，评估对象/动作描述错误与审核成本。
